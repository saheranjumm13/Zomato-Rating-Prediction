# 🍽️ Zomato Rating Prediction

A Machine Learning project that analyzes Zomato restaurant data and predicts restaurant ratings using Python and Streamlit.

## 📊 Project Overview

This project uses restaurant data from Zomato to perform data cleaning, preprocessing, exploratory data analysis, feature engineering, and machine learning.

A trained Machine Learning model is integrated with a **Streamlit web application** to predict restaurant ratings based on restaurant-related features.

## ✨ Features

- 📊 Restaurant data analysis
- 🧹 Data cleaning and preprocessing
- 🔍 Exploratory Data Analysis (EDA)
- ⚙️ Feature engineering
- 🤖 Machine Learning rating prediction
- 📈 Data visualization
- 🖥️ Interactive Streamlit application
- ⭐ Restaurant rating prediction

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset

The project uses Zomato restaurant data containing information related to restaurants, such as:

- Restaurant name
- Location
- Cuisine
- Rating
- Cost
- Online ordering
- Table booking
- Other restaurant-related features
## 🚀 How to Run

Follow these steps to run the Zomato Rating Prediction project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/saheranjumm13/Zomato-ML-Project.git

2. Open the Project Folder
cd Zomato-ML-Project

3. Install Required Libraries
pip install pandas numpy scikit-learn streamlit matplotlib seaborn

4. Run the Streamlit App
streamlit run app.py

5. Open the Dashboard

After running the command, Streamlit will provide a local URL such as:
http://localhost:8501

Open this URL in your browser to use the Zomato Rating Prediction application.
